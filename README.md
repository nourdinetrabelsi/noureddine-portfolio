# Noureddine Trabelsi — AI Portfolio

A personalized dark portfolio starter built with Next.js App Router, TypeScript, Tailwind CSS v4 and Lucide icons.

## Run locally

1. Install Node.js 20.9+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.

## Before publishing

- Verify the exact official English name of UIK and your degree.
- Replace the initial project summaries with factual descriptions: datasets, models, evaluation metrics and outcomes.
- Add real GitHub repositories and live demo URLs only when available.
- Add your email, LinkedIn and GitHub links to the contact section.
- Add a PDF resume in `public/resume.pdf` and then link it in the hero.
- Check the layout on mobile and run `npm run build`.

## Deploy

Push the folder to GitHub, import the repository into Vercel, and deploy with the Next.js preset.

No personal contact details, performance metrics, or repository URLs have been invented.
