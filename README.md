# Noureddine Trabelsi — AI & Data Portfolio

**Live website:** https://noureddine-portfolio-nine.vercel.app/

A personal portfolio presenting my background as a final-year AI engineering student, selected AI/data projects, and availability for a **4–6 month PFE internship starting February 2027**.

## What you'll find

- **CVMatchingAI** — semantic CV–job matching, skills-gap analysis and LLM-assisted recommendations; see the [project case study](https://noureddine-portfolio-nine.vercel.app/projects/cvmatchingai)
- **NLP CV analysis** — text analysis of a collection of 1,000 CVs
- **House price prediction** — regression-based machine learning
- **Sales dashboard** — business intelligence with Power BI

These are portfolio case studies. The underlying source code for these projects is **not currently published in separate public repositories**; project descriptions should not be interpreted as independently verified benchmarks.

## Tech stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Lucide icons
- Deployed on Vercel

## Run locally

**Prerequisites:** Node.js 20.9+ and npm.

```bash
git clone https://github.com/nourdinetrabelsi/noureddine-portfolio.git
cd noureddine-portfolio
npm install
npm run dev
```

Open http://localhost:3000.

For a production check:

```bash
npm run build
```

## Project structure

- `public/` — static assets, including project illustrations and the downloadable CV
- `public/projects/cvmatchingai/` — illustrative and redacted project screenshots
- `/projects/cvmatchingai` — dedicated CVMatchingAI case study route

## Privacy and accuracy

- Never commit API keys, `.env` files, `.streamlit/secrets.toml`, or real candidate CVs.
- Review screenshots for personally identifiable information before publishing.
- Portfolio illustrations and screenshots are not model-evaluation evidence.
- Any skill-coverage percentage should be interpreted in context, not as hiring probability or model accuracy.
- Review the publicly downloadable CV and contact details before updating or sharing them.
- Add verified model metrics and source-code/demo links only when they are available.
